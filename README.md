# PhoneDetector
Простой веб-инструмент для определения оператора и региона по номеру телефона.

# Как это работает
Приложение отправляет введённый номер телефона на внешний API (num.voxlink.ru) и отображает:

Полный номер (валидация)

Оператора связи

Регион (местоположение)

Предыдущего оператора (если был перенос номера)

# Использование
Откройте index.html в браузере

Введите номер телефона в поле

Нажмите на кнопку

Посмотрите результат — информация об операторе и регионе появится на странице
